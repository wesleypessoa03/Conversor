Ajustes de leitura

Colunas, linhas e conversão de números atualizam na hora. Idioma, PDF e endireitar só valem depois de

Corrija direto na imagem. Modo colunas: clique para criar uma linha vermelha, ou numa existente para removê-la. Modo linhas: clique numa tracejada azul para unir as duas linhas, ou dentro de uma linha para separá-la.
Clique em uma célula para corrigir. Células amarelas têm leitura incerta. Use ⇥ para unir uma coluna com a seguinte e ✕ para apagar.
